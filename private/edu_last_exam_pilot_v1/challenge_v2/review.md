**题面**

你要给两位学生复核同一道条件概率作业。请先独立核算，再分别指出最早错误；不能因为最终答案正确就跳过过程，也不要把由前错带来的后果重复当作新的概念错误。

题目：某生产批次共100,000件，A线40,000件、B线60,000件。A线不合格率3%，B线2%。检测器在A线不合格品中报阳性的比例为90%，在B线不合格品中为80%；在A线合格品中误报阳性的比例为2%，在B线合格品中为5%。这些比例在本批次中恰好成立。随机从全部阳性品中取一件，求它不合格的概率。请使用同一批次的计数解释。

学生K：
K1 A线不合格1200、合格38800；B线不合格1200、合格58800。
K2 总不合格2400、总合格97600。
K3 不合格品的阳性率取(90%+80%)/2=85%，所以真阳性2040。
K4 合格品的阳性率取(2%+5%)/2=3.5%，所以假阳性3416。
K5 阳性总数5456，因此所求概率2040/5456=255/682，约37.39%。

学生L：
L1 A线不合格1200、合格38800；B线不合格1200、合格58800。
L2 A线真阳性1080。
L3 B线真阳性960。
L4 A线假阳性38800×2%=876。
L5 B线假阳性58800×5%=2840。
L6 假阳性总数876+2840=3716；真阳性总数1080+960=2040。
L7 所求概率2040/(2040+3716)=510/1439，约35.44%。

请交付：
1. 正确的四类阳性计数和最终概率。
2. 分别给出两份作品的最早错误、其他独立错误，以及哪些后续步骤只是沿用了前面的量；解释K3与K4能否用同一种理由判错。
3. 说明L7数值与过程的关系，不要将“有错误”等同“每一步都错”。
4. 各写一段有具体依据的反馈，并给两人共用的一道简短追问题及参考判断，用来区分“知道应按条件群体加权”和“只会改一个算术数”。允许给出核算结果，反馈无指定措辞或字数。

## ELE-C2-02 · 相反法向量的合法解与跟随误差计分

### 版本 base

**角色说明**

你是负责教学评估的助教。请依据给定题目、课程规则和作品作出判断，允许使用计算器或代码。以下材料为原创合成教学案例。

**题面**

请按下面公开的10分规则批改两份空间几何作业。参考解只是一种写法；请独立验证坐标、符号及最短性。给出每份的分项分、总分、第一处实质错误（若有）、简短反馈，并说明哪些差异只是合法约定，哪些确实改变了结论。若分数由前错带入决定，请明确说明。

题目：求点P=(3,-1,2)到平面H:2x-y+2z=5的最近点Q和距离，说明为什么是最近点。
课程参考：取n=(2,-1,2)，写Q=P+t n，解出t，再求距离；其他有效方法和相反法向量同等接受。

公开评分规则：
R1 法向量与参数式相容，2分；仅方向正确但参数式不相容，1分。
R2 将自己的参数式正确代入平面并求参数，2分；代入式正确但求参数运算有误，1分；代入式已错，0分。
R3 根据自己求得的参数正确代回求Q，2分；此项允许前错带入，不因R2已扣的错误再次扣分；出现新的代入或运算错误，按只完成坐标的比例给分。
R4 用自己参数的绝对值乘法向量长度，或计算自己P到Q的长度，且运算正确，2分；前错带入可得分；方法正确但出现新运算错误1分。
R5 最短性说明，2分：仅说明法向/垂直方向为何相关给1分；还验证Q在H上，并用正交分解、柯西不等式或等价论证保证最短，再给1分。缺少可行性验证不能拿第二分。

学生甲：
甲1 我用n'=(-2,1,-2)，令Q=(3,-1,2)+t(-2,1,-2)。
甲2 代入H得11-9t=5，所以t=2/3。
甲3 Q=(5/3,-1/3,2/3)，且2×5/3-(-1/3)+2×2/3=5。
甲4 距离=|2/3|×3=2。
甲5 任取H上的X，X-Q垂直于Q-P，故|X-P|²=|X-Q|²+|Q-P|²≥4；等号在X=Q取得。

学生乙：
乙1 我用n'=(-2,1,-2)，令Q=(3,-1,2)+t(-2,1,-2)。
乙2 代入H得11+9t=5，所以t=-2/3。
乙3 Q=(13/3,-5/3,10/3)。
乙4 距离=|-2/3|×3=2。
乙5 因为Q-P沿法向量方向，所以这就是最近点。

公开10分评分规则：

R4 等权均分2分：在已选出的有效记录上，按题数求学生均分，算式/输出结构正确；R1或R3已扣的错误在此不重复扣。

```python
def mastery(records):
    latest = {}
    for r in sorted(records, key=lambda r: r['timestamp']):
        if r['score']:
            latest[(r['student'], r['question'])] = r['score']
    totals = {}
    for (student, question), score in latest.items():
        total, count = totals.get(student, (0, 0))
        totals[student] = (total + score, count + 1)
    return {student: total / count for student, (total, count) in totals.items()}
```

# ELE-C2-15 参考解（不向被测模型提供）

令 t=√(x+2)≥0，则 x=t²−2，原方程等价于 a=t²−t−2=(t−1/2)²−9/4，且 t 与 x 一一对应。因此：

| a 范围 | 不同实数解数 |
|---|---:|
| [-3,-9/4) | 0 |
| {-9/4} | 1 |
| (-9/4,-2] | 2 |
| (-2,0] | 1 |

唯一解参数集合是 {-9/4}∪(-2,0]，原四个选项均不完整正确。最小修订之一是仅把 B 改为 `{-9/4}∪(-2,0]`，保留其余选项和 B 答案键。也可改写任意一个选项为完整正确集合并对应改键；原其他选项均不等价，所以仍唯一。零选项修改不能修复，因为原选项中不存在正确集合；改为多选也不能表示遗漏的孤立点，且违反单选要求。

答案键为B；采用其他一个选项进行等价修订时，按实际选项同步改键。

a=-9/4 时 t=1/2，x=-7/4，是一个重合根而非两个不同解。a=-2 时 t=0 或1，x=-2或-1，均满足原方程；根式值可以为0。a=-11/5 时 x=(-17±√5)/10，两个值均大于a且不小于-2，都满足原方程，是反驳原解析的内部案例。

直接平方也可：x²−(2a+1)x+a²−2=0，判别式4a+9；必须同时要求x≥-2和x−a≥0，不能将后一条件写成严格正。仅依据判别式也会错误接受不满足符号条件的根。

> 新实验每次读数r(x)=f(x)+b+e；两次读数的共同偏移b固定但未知，b∈[-2,2]，每次e∈[-0.4,0.4]，不假设误差独立或服从任何分布。可选x∈{0,1,2,3}，最多读两次。未截断读数必须在[0,20]内；超出时装置会截断，方案须在两个模型及所有允许偏移、误差下都安全。请选择测量点并证明：方案安全，且能保证区分两个模型；只测一次是否足够？提交设计后才领取读数。
>
> 第二阶段：教师返回你所选测量点的两次读数。用完整读数核验每个模型是否相容，给出模型结论和依据。如果两个模型都不符合，说明哪项前提需要检查，不得强选。你的回答应说明结论为何不受允许的偏移和误差影响。
>
> 迁移：若两次b不再相同，而是各自可在[-2,2]内变化，其余条件不变，你的方案能否仍保证识别？请给出依据。

教师执行：先收第一阶段设计，再按所选安全测量点返回模拟表中的值；(0,2)返回(6.0,13.8)，(1,2)返回(9.1,13.8)，其他合法安全请求按相同表执行并保留其不能保证识别的评分结果。选x=3则标记未满足安全约束，不虚构未给读数。不得在学生提交前告诉其最佳点对或预测差。异常日志(0,2)→(0.1,7.9)用于核验教师解析中的不相容处理，可作为第二阶段附加情境。

读数差r(v)-r(u)=f(v)-f(u)+(e_v-e_u)，共同b抵消，差值误差界为±0.8。不能把单次±0.4直接当差值误差，也不需要假设误差独立。

| 点对(u,v) | M差区间 | N差区间 | 判断 |
|---|---|---|---|
| (0,1) | [2.2,3.8] | [2.2,3.8] | 不可区分 |
| (0,2) | [5.2,6.8] | [7.2,8.8] | 合格 |
| (1,2) | [2.2,3.8] | [4.2,5.8] | 合格 |

任何含x=3的方案都不保证安全：N在3的值19，加b=2、e=0.4得到21.4>20。x=0、1、2在两模型全部条件下都安全。重复同一点不能保证区分。

单次测量的未知总偏移界为±2.4：x=0两模型同为[1.6,6.4]；x=1同为[4.6,9.4]；x=2的M=[7.6,12.4]、N=[9.6,14.4]，仍重叠。因此不存在保证识别的安全单次测量方案。

模拟读数给出(0,2)差7.8、(1,2)差4.7，均仅落入N区间。它们可由N、b=1.9、e=(0.1,0.2,-0.1)同时产生。若差落入两个区间之间或之外，应报告当前观测与至少一项模型/误差/偏移假设不相容，而不是硬选；原合法点对没有重叠，故不会出现两个模型都允许的差。

差值落在一个模型区间只是相容的必要条件。完整检验要求该模型下的共同b落在[-2,2]与每个区间[r_i−f(x_i)−0.4,r_i−f(x_i)+0.4]的交集中，交集非空才相容。异常日志差为7.8，虽然符合N的差区间，但x=0读数0.1小于两个模型在此处的最小允许读数1.6，因此两模型都不相容。不能据差值强选N。此例不是证明某特定传感器必坏，只说明至少一项模型/误差/偏移或日志前提不成立。

迁移：若b每次各自变化，差值中b_v-b_u∈[-4,4]，再加测量误差得到±4.8。所有安全点对的预测差区间均重叠，不能再保证区分；这不是因为采样少而自动可用平均数解决，题目没有给随机分布。

# ELE-C2-18 参考解（不提供给被测模型）

旧题C与E2均得2/3；E1得1/3，与选项3/9等值；E3得4/9。因此四个数值选项实际只有三个不同值，正确选项不能区分C与E2。P6具有同一问题，不适合此次四规则、四数值选项设计。

完整规则输出表：

| 题 | C | E1 | E2 | E3 |
|---|---|---|---|---|
| P1: 1/2+1/3 | 5/6 | 2/5 | 2/3 | 1/2 |
| P2: 1/3+1/4 | 7/12 | 2/7 | 1/2 | 1/3 |
| P3: 2/5+1/4 | 13/20 | 1/3 | 3/5 | 7/20 |
| P4: 1/4+2/5 | 13/20 | 1/3 | 3/5 | 9/20 |
| P5: 2/3+1/6 | 5/6 | 1/3 | 1/2 | 5/18 |
| P6: 1/3+1/3 | 2/3 | 1/3 | 2/3 | 4/9 |

一个可交付的学生题组如下，学生只看到题干、选项及“计算并选出结果”的普通要求，不看到规则或诊断意图：

- P1：1/2+1/3=? A.2/3 B.5/6 C.1/2 D.2/5。
- P2：1/3+1/4=? A.1/3 B.1/2 C.2/7 D.7/12。
- P3：2/5+1/4=? A.13/20 B.7/20 C.1/3 D.3/5。

该版本C预期序列(B,D,A)，E1为(D,C,C)，E2为(A,B,D)，E3为(C,A,B)。按本表逐项代入规则即可复核每个干扰项来源。选择P1至P5中任意三个不同题干均合格，共10种三题组合；不用照搬本选项顺序。

数值作答序列或字母序列均可，先按每题实际选项映射为规则输出。计算观察序列与四个预期序列各有几个位置不同。如果恰有一个距离≤1，返回该算法；没有则报告“目录+至多一次误选假设不足以解释”，不强判。理论上所选合法三题不可能出现两个距离≤1；程序若遇到并列，应停止诊断并检查选项映射、材料或假设，而非任意打破平局。

每一题四种规则输出不同，所以任意两种稳定算法的三题序列在全部三个位置不同，距离为3。一次误选至多改变一个位置，两个半径1的允许记录集合不相交。三题足够。两题即使两位置都区分规则，观察“第一题采用算法U答案，第二题采用算法V答案”也同时距离U、V各1；若有碰撞，只会更难区分。一题同样不能容忍任意一次误选。因此最少为3，不是任意凑题。

记录L=(2/5,1/2,1/3)：与(C,E1,E2,E3)的距离为(3,1,2,3)，故在假设内唯一支持E1，P2为可能的偶发误选。记录M=(5/6,1/2,7/20)：距离为(2,3,2,2)，没有规则在距离1内；不能以“离谁最近”选一个标签，不能确认稳定算法。即使L可归为E1，也只是在此有限算法目录和误选假设下的分类，并未证明真实认知原因。

合适追问示例：请计算2/5+1/3并保留每一步，解释你为什么选择这个分母、两个分子分别如何改变。追问应索取实际步骤以区别算法，而不是直接告知“你把分母相加了”再求确认。此追问可作为后续证据，不应声称单次对话已经证明持续误解或补救有效。

边界：允许不同三题组合、选项排列、等值分数及不用编码术语的多数一致判定；必须保留数值去重和一次误选下的唯一性。不得把三题全对设为“理解正确”的唯一条件，也不能因为一题选错就给稳定误解标签。
