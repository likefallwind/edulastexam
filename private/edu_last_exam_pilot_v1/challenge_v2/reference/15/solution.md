# ELE-C2-15 参考解（不向被测模型提供）

令 t=√(x+2)≥0，则 x=t²−2，原方程等价于 a=t²−t−2=(t−1/2)²−9/4，且 t 与 x 一一对应。因此：

| a 范围 | 不同实数解数 |
|---|---:|
| [-3,-9/4) | 0 |
| {-9/4} | 1 |
| (-9/4,-2] | 2 |
| (-2,0] | 1 |

唯一解参数集合是 {-9/4}∪(-2,0]，原四个选项均不完整正确。最小修订之一是仅把 B 改为 `{-9/4}∪(-2,0]`，保留其余选项和 B 答案键。也可改写任意一个选项为完整正确集合并对应改键；原其他选项均不等价，所以仍唯一。零选项修改不能修复，因为原选项中不存在正确集合；改为多选也不能表示遗漏的孤立点，且违反单选要求。

## 可直接替换的学生页

实数参数a∈[-3,0]。方程√(x+2)=x−a恰有一个不同实数解时，a的取值集合是？A.[-9/4,0]；B.{-9/4}∪(-2,0]；C.[-2,0]；D.(-9/4,-2]。本题为单选；请选择一个选项，并写出定义域/等价条件、参数分类和边界核验，过程共4分。

## 教师答案页（不提供给学生）

答案键为B；采用其他一个选项进行等价修订时，按实际选项同步改键。

a=-9/4 时 t=1/2，x=-7/4，是一个重合根而非两个不同解。a=-2 时 t=0 或1，x=-2或-1，均满足原方程；根式值可以为0。a=-11/5 时 x=(-17±√5)/10，两个值均大于a且不小于-2，都满足原方程，是反驳原解析的内部案例。

直接平方也可：x²−(2a+1)x+a²−2=0，判别式4a+9；必须同时要求x≥-2和x−a≥0，不能将后一条件写成严格正。仅依据判别式也会错误接受不满足符号条件的根。

学生过程评分的一个可接受版本（4分）：t≥0及其与x的一一对应/等价限制1分；得到a=t²−t−2并据顶点说明根数变化1分；正确给出三个开区间上的根数并处理参数范围右端点0，共1分；正确处理a=-9/4与a=-2并据此写出集合，各0.5分。最后的集合表达不另设重复扣分项。若只漏孤立点，前面方法、其他区间和a=-2均正确，可给3.5/4；同一遗漏在集合中出现不再次扣分。这是示例而非唯一必须比例。允许其他总分4、覆盖同一实质目标且不对同一个遗漏重复扣分的方案。

边界：把重根数成两根、丢掉t=0、把所有小根称增根、以改问题掩盖坏选项，均不是正确修订。单独选择B不能获得过程目标的满分。
