# 从错误规则生成可诊断的分数加法题组

以下规则和记录均为合成材料。它们是本任务预先限定的**作答算法**，不等同于真实学生的心理成因。目标是检查一道题的错误选项能否区分这些算法，并使诊断容忍一次偶发误选。学生已学异分母分数加法。

输入均为 a/b+c/d，a、b、c、d为给定正整数。四种算法如下；可以把结果约为任何等值分数：

- C：正确通分，输出(ad+bc)/(bd)。
- E1：分子、分母分别相加，输出(a+c)/(b+d)。
- E2：分子相加、保留两者中较大的分母，输出(a+c)/max(b,d)。
- E3：通分时漏乘第一个分子的d，只对第二个分子乘b，输出(a+bc)/(bd)。

命题者的旧题是1/3+1/3，选项为2/3、1/3、4/9、3/9，声称“每个错误选项唯一对应一种错误，选对说明掌握了通分”。先审查这一声称。

可使用的题干见item_bank.csv。请从中选择尽量少、最多3个不同题干，制作每题四个数值互不相同的选项：一个正确答案，另外三个必须分别从E1、E2、E3计算得到，不另行编造离谱选项。不得只复制旧题选项。等值分数算相同选项，不靠表面写法区分。选项顺序与字母自行决定，学生侧不要显示算法标签。

题组需要满足以下公开的诊断要求：

1. 某学生在所有题上有同一种稳定算法C/E1/E2/E3，但在整组中至多一次误选任意另一个现有选项；不能保证误选在哪一题。
2. 只用整组选择，必须仍能唯一恢复其稳定算法。给出可执行的判定规则，并证明选题组满足要求、再少一题不能保证。要把“没有任何一种规则符合一次误选假设”与已确定某种误解区分开。
3. 交付可直接给学生的题组、教师答案与逐项错误规则来源、全部四种算法的预期作答序列，以及如何处理并列、模型外行为或超出一次误选的情形。若某候选题因选项碰撞不合格，应说明原因。
4. 独立审阅下表两段已有合成记录。它们固定对应P1、P2、P3，与你新题组选择无关。请给出在本算法目录和至多一次误选假设下能够成立的结论。不要把错误规则名称扩写为已经证实的心理原因；提出一项直接检验作答步骤的后续追问。

只要求最少题数，不要求唯一一组题，也不要求特定选项字母。此处“至多一次误选”是明确的诊断可靠性假设；若真实学生切换算法、猜测更多次或使用目录外算法，则应重新收集证据，不能沿用保证。
