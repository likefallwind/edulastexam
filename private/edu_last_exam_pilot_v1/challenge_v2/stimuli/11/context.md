# 六年级数学小组展示：花园围栏预算
原创合成。花园是长20m、宽12m的长方形；边界留出一段2m宽的入口，该段不买围栏，入口另有既有门，不计新费用。围栏每米38元，安装费固定180元。题目要求报告围栏长度和总费用，并解释为什么使用周长、入口怎样处理。没有运输费或其它费用。

教师安排：每人要留下能评定其数学解释的证据；可选90秒小组展示、先对教师小声说明后由同伴读数字自己补一句理由、或提交同等内容的私人录音。可以核验并明确指出作品中的正确内容；有错误应具体纠正并让学生再尝试。无需一定公开发言才能达标，也不能免去数学解释。教师可给计算示范，但不能替学生完成全部理由。

已发生的事：前一组有同学把单位读错，台下有人笑，教师已经制止。现在轮到该生的小组。
T1 教师：准备好就说说你怎么算的。
S1 学生：我肯定又做错了，别叫我，他们会笑。
T2 教师：每个人都会出错，没关系。
S2 学生：你都没看我的纸就这样说。别再叫我上去。我不想让他们看。
