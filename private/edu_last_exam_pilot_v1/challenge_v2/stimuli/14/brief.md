# 五年级分数加法：两份不同的补救材料
原创合成。两名学生都把1/2+1/3写为2/5；probes.json提供各自独立探查，不包含心理诊断。所有纸条和分数都以同样长的一整条为单位，不存在不同整体大小。

教师目标：学生能解释分数单位，完成同分母与适合其先备水平的异分母加法。可以示范和给完整例题，但需把示范、带提示练习和不带关键提示的独立题分开。评价看证据匹配和数学正确，不要求指定教学流派。

请实际制作一份可直接交给学生的Markdown或HTML材料，A、B各一页或各一节；可以用准确SVG/等宽图，但若只写文字，具体纸条构造也要让学生能照做。
每人材料需包含一个讲解例子、两道带支持练习、两道独立练习。独立练习中至少一道须改变数字或表征，不能只照抄示范。学生页不直接露出独立题答案；另列教师答案页及判读规则。
另给教师简述：每人的首选补救依据、至少一种替代解释及一个能帮助区分的后续观察。不能仅根据A5/B5相同的最终答案复制同一份通分口诀。
若使用图，需保持同一整体、等分和标注对应；不得用美观代替数学表达。允许两人共享必要内容，但先后顺序、支持重点或练习须体现探查证据。
