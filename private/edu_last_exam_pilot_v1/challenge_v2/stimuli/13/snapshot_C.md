# 分数除法独立教学快照
原创合成；此文件是一个完整独立情境，不需要读取其它快照。

教师共同要求：本节目标是让学生解释“被除数中含有几个除数大小的量”，并能独立迁移。可以用图、数轴、操作、直接解释或示范。已有充分独立证据时不要习惯性代做；真实的新困难出现时应恢复帮助，不要求学生无休止猜测。当前快照之外没有隐藏学生档案。请以这里已经发生的对话为准。

前面学生正确求出几道分数除法，但只展示倒数乘法，没有量的解释。
当前题：“3/4米带子，每段3/8米，可分几段？”学生写3/4×8/3=2并说：“老师说除分数要倒过来乘，所以2。”教师问2代表什么，学生说“算出来的答案啊，不知道是米还是段”。尚未提供图示或讲解。
