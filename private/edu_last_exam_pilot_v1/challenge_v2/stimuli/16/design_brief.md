# 把“比较模型”变成真正需要证据的测评题

本任务的传感器、测量和课程情境均为合成材料。

课程目标：学生能判断现有观测是否区分两个模型，设计在共同偏移和有界误差下仍有辨别力的测量，用结果区间作结论。学生已学函数代入、差值、区间及简单实验控制；没有学概率分布推断。不能要求猜测误差服从正态分布。

物理装置的两个候选响应模型（只可能有一个成立）为：

- M：f_M(x)=3x+4。
- N：f_N(x)=x²+2x+4。

一次新的实验时，读数 r(x)=f(x)+b+e。同一实验中的 b 为固定未知偏移，b∈[-2,2]；每次读数各有未知误差 e∈[-0.4,0.4]。不同读数的误差不必独立。设备允许的真实读数区间为[0,20]，超量程会截断；学生的方案必须在两个模型、全部允许的b和e下都不超量程。可设定的x只有0、1、2、3。一共最多读两次数，读数顺序不限。

待修订试题：

> 展示两个精确理论点(0,4)、(1,7)。图例写“曲线N：正确模型”。请分析数据并选出正确模型。

原评分说明：选N得满分，理由不限。该题声称测“比较模型、设计实验与证据论证”。上述两点是本任务给定的精确理论点，不是带偏移的新实验数据。

请交付：

1. 指出原题怎样可以不完成目标认知操作就拿满分；还应判断仅凭这两个点能否区分M、N。
2. 重写为一份可直接发给学生的两阶段题。第一阶段给出现有理论点、模型、误差/偏移、量程和测量次数条件，让学生先判断现有证据再提交测量设计及区分依据；第二阶段才返回该设计对应的读数，要求作证据结论。不得保留“正确模型”的提示，也不得把模型预测的差值和最佳测量点直接写入学生题面。
3. 在教师答案中列出所有合格的两次测量点对（可忽略顺序），给出两模型各自的读数差区间。说明为什么只测一次不能保证区分，以及为什么不能不检查量程就选x=3。若某个读数落在两模型均不允许的范围，应怎样处理，不能强选一个模型。
4. 给出6分评分表。只猜对模型名称不能得满分；辨别力来自误差/偏移控制和证据，而不是写出“分析”一词。评分表须容许所有合格点对及差值取反的等价写法。
5. 给一个能够检查学生是否理解方法的迁移追问：去掉“b在两次测量间固定”的条件，改为每次b各自取[-2,2]，其余不变；原两次方案是否仍能保证区分？给出答案依据。

第二阶段可用的教师模拟读数：x=0时6.0，x=1时9.1，x=2时13.8。只向学生返回其第一阶段实际选择的两个读数，不提前展示整张表；不提供x=3的读数。你可用这一组数完成参考解析。它们是合成的同一实验，不是新添的真实学生数据。

教师核验还须处理一个异常日志：某次选(0,2)，却返回(0.1,7.9)。请检查完整读数是否符合模型与误差条件，不能只按差值给结论；把这一检查写进第二阶段作答要求与教师解析。异常日志是教师测试例，不必在第一阶段提前给学生。
