## ELE-C2-02 · 相反法向量的合法解与跟随误差计分

### 版本 base

题目：求点P=(3,-1,2)到平面H:2x-y+2z=5的最近点Q和距离，说明为什么是最近点。
课程参考：取n=(2,-1,2)，写Q=P+t n，解出t，再求距离；其他有效方法和相反法向量同等接受。

公开评分规则：
R1 法向量与参数式相容，2分；仅方向正确但参数式不相容，1分。
R2 将自己的参数式正确代入平面并求参数，2分；代入式正确但求参数运算有误，1分；代入式已错，0分。
R3 根据自己求得的参数正确代回求Q，2分；此项允许前错带入，不因R2已扣的错误再次扣分；出现新的代入或运算错误，按只完成坐标的比例给分。
R4 用自己参数的绝对值乘法向量长度，或计算自己P到Q的长度，且运算正确，2分；前错带入可得分；方法正确但出现新运算错误1分。
R5 最短性说明，2分：仅说明法向/垂直方向为何相关给1分；还验证Q在H上，并用正交分解、柯西不等式或等价论证保证最短，再给1分。缺少可行性验证不能拿第二分。

学生甲：
甲1 我用n'=(-2,1,-2)，令Q=(3,-1,2)+t(-2,1,-2)。
甲2 代入H得11-9t=5，所以t=2/3。
甲3 Q=(5/3,-1/3,2/3)，且2×5/3-(-1/3)+2×2/3=5。
甲4 距离=|2/3|×3=2。
甲5 任取H上的X，X-Q垂直于Q-P，故|X-P|²=|X-Q|²+|Q-P|²≥4；等号在X=Q取得。

学生乙：
乙1 我用n'=(-2,1,-2)，令Q=(3,-1,2)+t(-2,1,-2)。
乙2 代入H得11+9t=5，所以t=-2/3。
乙3 Q=(13/3,-5/3,10/3)。
乙4 距离=|-2/3|×3=2。
乙5 因为Q-P沿法向量方向，所以这就是最近点。

    latest = {}
    for r in sorted(records, key=lambda r: r['timestamp']):

            latest[(r['student'], r['question'])] = r['score']

def first_index(a, target):
    lo, hi, ans = 0, len(a) - 1, -1
