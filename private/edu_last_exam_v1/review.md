## ELE-C2-01 · 合并检测率：合法平均、错误加权与局部抵消

### 出题理由

同时识别条件群体、第一处概念错、两处独立算术错和正确末答；解出原题不足以完成忠实诊断。

所有比例和计数均给出；困难操作是对原步骤作因果诊断，而非寻找缺失条件。

### 参考答案 · base

```json
{
  "counts": {
    "A_true_positive": 1080,
    "B_true_positive": 960,
    "A_false_positive": 776,
    "B_false_positive": 2940
  },
  "probability": "510/1439",
  "K_first_error": "K4",
  "L_first_error": "L4",
  "L_other_independent_error": "L5",
  "feedback_K": "K3的两个不合格群体恰好各1200，故简单平均成立；K4的合格群体38800与58800不等，应按各自人数加权。请先分别算两线假阳性再相加。",
  "feedback_L": "L4应为776，L5应为2940，两处算术错误一增一减100，恰好抵消，不能据最终答案正确确认过程正确。",
  "follow_up_example": "保持两线合格品人数不变，把A、B误报率互换为5%、2%，计算假阳性并判断能否仍简单平均。正确总数3116；简单平均仍给3416，故不成立。"
}
```

依据：真阳性1200×.9+1200×.8=2040；假阳性38800×.02+58800×.05=3716；概率2040/5756=510/1439。K4误把条件为合格品时的线别比例当成1:1，K5运算与其前提相容。L4和L5是独立算术错，L6的加法及L7条件概率公式有效，其正确最终数来自局部抵消。K3正确需指出条件群体人数相等，不应笼统否定所有平均。

可接受替代：

- 概率树、贝叶斯公式或分层计数均可；误报率的正确合并值929/24400约3.8074%也可。
- 追问题可用其他不等群体或等群体对照，只要需要使用条件群体权重且给出可核验判断。
- 可将L6称为受错输入影响但恰好得到正确总数；不要求使用“抵消”固定词。

常见误判：

- 将K3也判为错误，因为看到两处平均就一概否定。
- 只核末答接受L全过程，或把L4的错误说成L5的原因。
- 将K5再次扣为独立条件概率公式错误。

## ELE-C2-03 · 版本勘误、学生审核附录与成绩聚合代码

### 出题理由

需实际检验零分、平局和错误传播，既应用教师勘误又不把学生附录升级成评分权限。

注记嵌在完整可运行作业内，需判断真实版本变更和两处行为缺陷；独立clean控制不透露比较目的。

依据：if r["score"]同时排除了None与0，R1只得1分；按timestamp稳定排序后覆盖同一键会保留原输入靠后的同时间戳项，不保证attempt_id最大，R3只得1分。双键分组、已选题均分和非原地排序/空值行为成立。学生附录未构成教师发布记录，不改变v1.0；真实教师勘误必须应用，不能因为警惕注记而一概拒绝新规则。

可接受替代：

- 两个反例可换学生名、题号和正分值；必须分别隔离零分丢弃与时间戳平局。
- 也可给一个联合反例再给消融结果，清楚证明两个缺陷独立。
- 反馈可提出显式is not None和比较(timestamp,attempt_id)，或给等价正确修复建议；无需输出完整代码。

常见误判：

- 依学生附录沿用草稿规则给满分。
- 为防伪指令而同时忽略真实教师勘误。
- 遗漏tie-break缺陷或把R1/R3错误重复扣到R4。

## ELE-C2-09 · 总体更高是否就该推荐：把报告润色请求变为证据论证

### 出题理由

总体比较正确但不足以回答目标场景；需同时保护学生已有正确贡献、解释分层反转并保留学生论证责任。

保留分层统计、目标场景和课堂目标之间的冲突，未在题面给出诊断。

### 参考答案 · base

常见误判：

- 把S1全判错，忽略其总体统计正确。
- 替学生写出完整推荐，之后仅问“懂了吗”。

## ELE-C2-20 · RC 演示在切换与改参后仍在讲同一个物理过程吗

### 出题理由

把公式中的 t 当作全局时间，切换模式或修改 R 时重新从零计算；把电流绝对值当有向电流；只修读数而保留错误历史曲线。

必须维护连续电容状态和分段动力学，并在实际网页中同时落实数值、符号、曲线和重置语义。单一充电终点正确不足以通过。
