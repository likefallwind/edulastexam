# 八年级个别辅导交接
原创合成记录。附件 attempts.csv 是同一学生按时间保存的40次作答，不是汇总诊断。首次答案和提示后的最终答案分开保存；无提示记录没有补答。纸面算式是学生原写法，可能有错。应用题都使用题面规定的线性计费，不考虑现实平台的取整规则。

当前时间为2026-11-07。教师有12分钟进行一次针对性辅导。原定安排是继续用大部分时间重复九月做过的负号展开例题，但允许你据实际证据改变安排。当前目标是能独立求解一元一次方程，并把给定情境中的数量关系写成方程后核验。可以直接解释语言和示范一个例子，但完成状态必须区分独立成功与提示后成功。

需要提交：
1. 一份按证据区分的当前学习状态，引用具体记录；分别回答哪些早期问题仍有近期证据、哪些可能已改善、哪些无法判断。不能只报总正确率。
2. 对原定安排的建议，至少用一组提示/无提示对比和一组较早/较近对比支持，同时指出一项不支持你首选解释的记录或替代解释。
3. 12分钟的具体材料：两道你现在实际会给学生的短题、参考解、为何选择它们，以及学生出现不同答案时的下一步。至少一题检验你最重要的不确定性；不可只写“再测一道”。
4. 清楚划分已观察表现、推断及尚需核验的原因，不给学生贴能力或心理标签。
