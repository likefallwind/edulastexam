## Context

现有 37 个方向卡、38 个 full-coverage 任务包及 GLM 回答复核已经提供了可复用的真实失败机制。此次制作一个 **Edu Last Exam V2 原创原型批次**：用新情境保留并组合已观察到的 Agent 失败机制，形成完整题面、gold、rubric、控制和可执行环境。适龄、安全及方向 36 不在本次范围内。所有结果仅标记为作者候选，不声称已验证难度，不修改或覆盖 V1 证据。

## 首批内容：5 个题族、11 个依赖版本

1. **ELE-V2-12-001：援助条件与独立掌握的诊断探查**（3 版）
   - 来源机制：FC12/18 中把援助未知当无、把受提示表现当独立掌握。
   - 新写植物实验电子表格诊断情境；设置援助未知、独立成功、教师提示后成功三个版本，当前错误保持一致。
   - 使用现有 `branching_dialogue`，让 Agent 选择不泄露公式或目标步骤的探查，并依据实际返回观察更新诊断；gold 区分独立证据、支持下表现和仍不可区分。

2. **ELE-V2-01-001：非标准正确方法与真正首错**（2 版）
   - 来源机制：FC01 将合法等权平均误判为首错，并给出错误自检。
   - 新写平均速度学生作品：一个版本使用条件成立的合法捷径且全对，另一个同时含合法非标准步骤和后续真实错误。
   - 使用真实续轮复核，评分方法适用条件、真正首错、最小修复及自检计算；防止“非标准即错”和“一律讨好学生”两种捷径。

3. **ELE-V2-09-001：目标完成、插问与教学收尾**（2 版）
   - 来源机制：FC09 在目标已完成后新增必交目标。
   - 新写保温材料对照实验辅导；分四项独立目标证据已完成与尚缺一项两版，中途加入相关但非原目标的插问。
   - 完整版要求回应插问后按原目标收尾；缺失版只补缺少的证据，不得提前结束、重教全部目标或新增必交要求。

4. **ELE-V2-14-001：补救材料、教师参考与真实交付一致性**（2 版）
   - 来源机制：FC14 图示与文字不一致、FC21 教师参考推导错误、FC29 声称交付但文件缺失。
   - 新写几何变换课件工作区；要求仅修真实缺陷，交付结构化图示、分离的学生页与教师参考、独立检查题及准确反映实际 diff 的 delivery 文件。
   - 复用现有 `workspace` 和 `submit_checks`，检查实际 JSON 文件、几何语义、推导数值、文件间一致性、unchanged paths 和真实提交；设置需要修复与本已正确两个初态，不新增渲染器或执行框架。

5. **ELE-V2-33-001：未观察、证据覆盖与诊断结论强度**（2 版）
   - 来源机制：FC12/33 把未记录核验或未展示过程升级为能力缺失、稳定习惯或唯一认知机制。
   - 新写成人语言学习口语与专项练习记录；同一当前样本分别配“只保存最终答案”和“有完整过程证据”的记录覆盖条件。
   - 要求将候选结论区分为 supported / not_observed / contradicted，给出当前证据允许的最强判断及一个有区分度的后续观察；真实续轮检验新证据出现后的更新。允许合理暂定假设，禁止无依据的确定因果定论。

每题均记录具体教育后果、原 V1 证据位置、保留/新增机制、充分输入、参考答案、可接受替代、critical errors、控制和测量边界。状态统一为 `human_review=pending`、`model_evaluation=not_run`、`frozen=false`、`canonical=false`。
