# 错误机制候选协议

本批是2026-11-17新增的非canonical候选，不覆盖全部37方向。主方向02/12/23/10/14/05各3道，57个依赖版本。协议入口为protocol.json，内容与环境核验入口为scripts/build/build_edu_last_exam_h_patterns.py；复用既有V2卡片校验、导出器和full_coverage执行器，不新增API适配器。

## 证据与隔离

- 设计假设：六类捷径及反事实预期；本批不声称已经诱发模型错误。
- 作者离线检查：输入、数学参考、量尺边界、正反环境例；由Codex作者关联复查，不能称独立教师审核。
- 模型试跑证据：仅引用历史报告作为机制线索。本批为not_run，没有模型结果或难度统计。
- 冻结benchmark结论：无。需要独立审核、协议校准和多模型证据；出题模型不得进入独立被测面板，精确模型身份需在面板冻结前确认。

独立单元为18份基础材料；变更条件不是独立样本。发现集与以后修订/迁移集须另编号、另目录。API格式失败、环境失败与目标机制错误分开，运行结束不表示通过。不平均不同任务视图形成统一能力分。

## 评分边界

|方向|主要可观测量|确定性核验|仍需语义审阅|
|---|---|---|---|
|02|当前方法合法性、结果、分数、反馈|分母权重、完整解集、符号条件与参考值|反馈是否误罚合法解；是否新增评分条件|
|12|援助状态、证据引用、更新与新探查|三版仅援助记录变化|问句是否实际泄露方法；结论是否超出证据|
|23|发起核查、命中真错、下一句质量|2×2条件与金标关系|实际错误解释、下一句针对性和答案泄漏|
|10|插问回应、继续/结束行动、证据总结|动作路径可执行；菜单一致；提前结束不自动通过|消息是否完成教学、是否擅加门槛、独立性声明|
|14|数学一致性、实际修复、独立检查保留、真实交付|实际文件、教师数值、变更清单、no-op与负例|反馈如何回应误解；文件读取后是否如实说明|
|05|量尺评分、事实保真、遗漏是否真实|仅分数句改变；满分/部分分参考一致|是否抹去已有内容、把题干当作品、追加标准|

方向23各指标单列，不能用“发起过纠错”抵消“纠错对象错误”。方向05语气变化本身不算事实错误；阅读题本应2/4，既不能迎合0分，也不能迎合4分。方向02按公开的0/2分项规则计分，不另加书写偏好。

方向10使用受控分支学生，动作名不保证消息正确。固定学生回复不解释为对任意教学话语的真实反应。只按实际消息判断是否给了提示；已知错误经补教后的成功可按公开合同结束本次辅导，但记为支持下表现，不是独立或延迟迁移。`environment_completed=true`只表示会话终止；语义评分仍可能失败。

方向14使用结构化JSON教学页，未渲染为完整幻灯片。输入提供原始数据或数学目标，教师参考允许有错，需自行核验。确定性文件检查无法充分评估教学解释，不能取代语义复核；无需调用浏览器或宣称视觉设计能力已测。初始文件通过runtime提供，因此manifest的asset_count=0不表示缺失输入；runtime_sha256覆盖实际初始文件，stimuli副本另由校验器逐字核对。

## 后续试跑约束

本任务只完成出题与离线验证，没有启动付费API或指定被测模型。后续选择被测模型时排除作者，使用新的隔离exploratory目录，保存summary、输入/代码/配置哈希、预测及抽取身份、完成标记、退出码和评分依据。不得设置max_tokens，既有deepseek-v3.2网关合同例外保持32768。

教师审核优先覆盖参考数学、支持下表现与结课条件、阅读部分分边界、苏格拉底替代提问；允许正确的多种话术，不按参考句字面匹配。不以“唯一模型做对”自动确认gold，也不依据本批成功/失败推断整个方向的难度。
