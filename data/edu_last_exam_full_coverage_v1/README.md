# 全方向探索规范

`implementation_matrix.json` 是37项最初实施路线及当时缺口的规划快照，保留 `planning_only`，不将规划字段回填为实验事实。

- `authoring_contract.md`：候选题、参考、对照及运行协议的共同结构。
- `provider_contract.json`：本次GLM-5.3-Flash接口条件与官方来源。
- [实际题包manifest](../../private/edu_last_exam_full_coverage_v1/manifest.json)：当前导出身份、资产哈希、数量和边界。
- [逐项实现状态](../../reports/full_coverage_v1/implementation_status.html)：由实际候选生成的覆盖表；不等于所有子结论已被直接测量。

模型回包、初评分数、完成标记与退出码只保存在每次独立运行目录。独立教师审核和正式冻结状态不由一次试跑自动更新。
