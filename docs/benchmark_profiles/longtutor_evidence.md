## 这是哪个子评测

- 家族 LongTutor 面向长程辅导场景，本仓库实现了三个子评测：本页的证据定位、学生状态诊断、以及长历史下的教学动作选择。
- 三者共享同一批长程辅导对话，但测的是链条上的不同环节：先找得到证据，才谈得上判断学生状态，再谈得上选对教学动作。
- 本页内部再按记忆类型拆成三个取分维度：单条信息提取、跨会话推理、幻觉核查。

## 出处与背景

- 官方仓库只提供 pipeline 脚本，没有可直接执行的评测实现，本仓库自行移植为可复现的 adapter。
- **协议对齐（2026-11-06）**：预测端复刻官方 `eval_ai_tutor.py` 发布版默认配置（`use_feature=False, use_teach=False`）——常驻官方 system prompt（诊断 Schema）、合并 JSON 调用（同一轮回答 memory 问答+诊断+教学）、历史取最近 200 条按官方纯文本拼接、采样温度 0；判分端复刻官方 `compute_ai_tutor_eval_metrics.py`——空白折叠精确匹配优先，兜底裁判用官方 `{"match": bool}` 语义等价提示词。裁判模型为本地面板（官方用 GPT-5），绝对分仍不与论文榜单直接对照，横向比较可用。

## 任务与判分

- 三个维度各自按准确率计分，分开取值而不是合成一个总分。
- 分开是必要的。**13 号实测（v7/R28，分析日 2026-11-02）**的三个 accuracy 格均为当前面板 n=8：Information Extraction 均分 9.602、SD=0.126（ceiling + low_variance），Multi-session Reasoning 均分 6.636、SD=0.496（low_variance），Hallucination Check 均分 7.272、SD=0.654（未受限）。合成总分会稀释这些不同的信号。（注：该面板数字产生于协议对齐之前的旧协议运行。）

## 局限与注意

- 调用与判分协议已对齐官方发布版脚本；剩余差异是裁判模型替换（本地面板 vs 官方 GPT-5）与 evidence 侧同一学生样本的三条查询各发起一次相同调用（官方为一次合并调用内作答，内容等价、成本三倍）。
- **幻觉检查的判分口径差（2026-11-07 官方协议重跑实测）**：MiniMax-M3 幻觉检查 70.5%→58.3%，其中约三分之二的失败是"拒答式表述"（模型答"没有/记录中未作答"而 gold 为 "Unknown"）——旧自制裁判有 Unknown 等价规则判其正确，官方裁判没有该规则判其错误。按官方口径真实幻觉（编造实义内容）约 14%。若上游未来在官方裁判中补充 Unknown 语义规则，该维分数会回升约 12pp。
- 在当前面板中，单条信息提取同时有天花板和低方差，跨会话推理也触发低方差；三维里只有幻觉核查未受限。这是带日期的面板/指标级结论，不等于另外两维永久没有信息。
- 幻觉核查这一维值得单独关注——长程辅导里模型凭空补出的"学生说过的话"，会污染后续所有个性化判断。
