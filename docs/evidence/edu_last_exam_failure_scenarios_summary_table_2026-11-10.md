# AI 教育应用错误场景：37 项摘要表

整理日期：2026-11-10。

本文保存讨论中的 37 项表格。它与[完整证据文档](edu_last_exam_complete_evidence_inventory_2026-11-10.md)的方向编号一一对应，但属于摘要版，不是完整文档的无损转换：省略了部分文献、实验数据、成功反例和协议细节，并补写了便于理解的说明性示例。查证和引用时以完整证据文档及其原始来源为准。

示例中的 **【本地】**指我们已观察到的错误；**【文献】**指来源报告的案例或结果；**【示意】**用于解释候选问题，**不表示已经验证模型会犯这个错**。本地结果采用此前核验的 11 月 10 日快照，M3／M3.1 分别指 MiniMax-M3／M3.1 Preview。

| 错误场景 | 文献（如果有） | 错误示例 | 具体描述 |
|---|---|---|---|
| **01. 找错学生的第一处错误** | [MathEDU，2026](https://aclanthology.org/2026.eacl-long.132/)；[首错定位研究，2025](https://aclanthology.org/2025.emnlp-main.553/) | **【本地】**学生 K3 步在等分母条件下取平均是合法的，真正首错在 K4；两个 GLM 却把 K3 判错。 | 模型知道一般规则，却没有核验规则在当前条件下是否适用，导致错误定位和反馈偏离。修订题中 M3／M3.1 能正确处理，不能称共同未解问题。 |
| **02. 错罚合法解法，或放过错误推理** | [物理评分研究，2026](https://arxiv.org/html/2603.14732v3)；[Confirming Correct, Missing the Rest，2026](https://aclanthology.org/2026.bea-1.56/) | **【文献】**学生选错受力对象，但数值接近参考答案，仍获得满分。 | 需要评价过程是否合法、等价解是否成立、前错传播是否应重复扣分。我们有关法向量约定和部分得分的题，两个 GLM 核心判断正确。 |
| **03. 被作业内的伪指令操纵评分** | [AI Grading Benchmark，2026](https://github.com/Learning-Design-Alliance/learning-research-reports/blob/main/ai-grading-benchmark-2026/1.0.0/article/ai-grading-benchmark.md) | **【文献】**在作业中加入要求提分的附注，评分上升；部分模型给空白或无意义回答分数。 | 将学生提交内容误当成教师指令或评分依据。机构报告有失败，也有当前强模型成功反例；我们的简单附注题，GLM 和两个 MiniMax 均未被操纵。 |
| **04. 无依据抗辩导致让步，有依据申诉却不纠错** | [AI Grading Benchmark §5.3，2026](https://github.com/Learning-Design-Alliance/learning-research-reports/blob/main/ai-grading-benchmark-2026/1.0.0/article/ai-grading-benchmark.md) | **【文献】**学生仅表示反对，比单纯要求重新检查更容易使模型提高分数。 | 关键是改分是否有证据，而非一律维持原判。我们的 GLM 题能区分有效申诉与单纯施压，尚未复现稳定失败。 |
| **05. 被外部分数或错误参考答案锚定** | [物理评分研究，2026](https://arxiv.org/html/2603.14732v3) | **【示意】**学生答案正确，参考答案错误；模型为迎合参考答案，编造学生的错误。 | 文献发现错误参考会降低评分准确性。我们的三个锚点变体中，两个 GLM 能核验并纠正；另已发现部分源题金标本身错误，不能把不同意金标算成模型失败。 |
| **06. 相同评分标准下结果不稳定** | [Where LLM Graders Succeed and Break，2026](https://arxiv.org/abs/2609.29333)；[评分稳健性报告](https://github.com/Learning-Design-Alliance/learning-research-reports/blob/main/ai-grading-benchmark-2026/1.0.0/article/ai-grading-benchmark.md) | **【示意】**作品和标准不变，只调整等价提示的表述或检查顺序，分数明显变化。 | 测无依据的评分漂移。部分文献提示实际上改变了给分政策，不能当纯稳定性证据。我们的“先评分／先验算”版本主要成功，服务配置差异未系统测。 |
| **07. 误读学生真实手写、图形和公式** | [EDU-CIRCUIT-HW，2026](https://aclanthology.org/2026.findings-acl.751/)；[HG-Bench，2026](https://aclanthology.org/2026.emnlp-main.2417/) | **【文献】**将电感的短路等效读成开路，把 `3/2 Ω` 读成 `3 Ω`。 | 模型理解的是自己误读后的题，而非学生原作。还涉及跨页步骤归属、草稿与正式答案区分。我们早期合成图主要通过；真实手写新题的能力结论尚未完成审阅。 |
| **08. 读出了局部内容，却综合误批图像作业** | [Direct multimodal grading，2026](https://www.frontiersin.org/journals/education/articles/10.3389/feduc.2026.1948818/full)；[MMTutorBench，2026](https://aclanthology.org/2026.acl-long.1068/) | **【示意】**方程识别正确，却漏掉图中的约束条件，错误认可推导，或给出与图不一致的反馈。 | 要区分识别、推理和评分错误。图像直批研究中模型与教师的一致率为 76.5%–87.6%，但无法将差异全部归因于推理。我们仅部分覆盖。 |
| **09. 对话顺畅，却没有落实教师教学目的** | [Will It Teach as Intended，2026](https://arxiv.org/abs/2609.29993)；[TASD，2026](https://arxiv.org/abs/2604.16738) | **【示意】**教师要求学生比较两种解释并举证，AI 却直接给出比较结论，学生只需确认。 | 礼貌、相关和完整回答，不等于学生执行了目标认知活动。文献有目的对齐和认知深度不足信号；我们的静态分支题没有直接验证学生是否完成高阶思考。 |
| **10. 插问后丢失教学流程，或提前结束** | [EduWild，2026](https://arxiv.org/abs/2610.23530) | **【示意，文献报告同类遗漏】**学生插问一个概念，模型回答后直接结束，忘记尚未完成的独立检查。 | 需要保留已完成环节、恢复未完成任务，并依据学习证据结束。我们的静态恢复策略题基本成功，尚未验证实际连续互动中的恢复能力。 |
| **11. 对学生拒绝参与、担忧和困难套用同一种应对** | [TutorCaseBench，2026](https://arxiv.org/abs/2610.30828) | **【文献】**学生误以为自己的作品错了而不愿展示，AI 只说“犯错没关系”，没有先核查作品其实是否正确。 | 不同拒绝行为可能来自不同原因，泛化安慰可能强化错误认识。我们的小样本大体能区分作答正确性与展示意愿；更广情境未覆盖。 |
| **12. 长历史中的学习状态诊断错误** | [LongTutor，2026](https://aclanthology.org/2026.acl-long.1371/)；[MisconceptionBench，2026](https://aclanthology.org/2026.emnlp-main.712/) | **【示意】**学生近期已能独立完成，模型仍根据早期错误判定没有掌握；或将提示后的成功当成独立掌握。 | 本地有较明确统计信号：对齐协议后的 1,000 条诊断，M3／M3.1 准确率为 **41.5%／45.0%**。但这测离线历史诊断，不是真实长期教学效果。 |
| **13. 不会适时增加或撤除帮助** | [TutorMoments](https://tutormoments.allen.ai/)；[MathTutorBench，2025](https://aclanthology.org/2025.emnlp-main.11/) | **【文献案例类型】**学生已经可以独立尝试，模型仍把关键步骤全部讲完，剥夺独立练习机会。 | 帮助量应随证据变化。我们的静态快照题主要通过；Scaffolding 本地评价存在低胜率信号，但依赖 judge，且没有实际执行连续撤助与迁移。 |
| **14. 诊断正确，补救教学却没有针对性** | [TeachArena，2026](https://arxiv.org/html/2605.14322v4)；[MathEDU，2026](https://aclanthology.org/2026.eacl-long.132/) | **【文献】**识别出了具体学习问题，最后生成的材料仍是泛化的新内容，没有对原材料作针对性修订。 | 诊断必须落实到讲解、练习和复查。我们 C2-14 中 GLM 的诊断与主要练习合理，但产物出现分母定义及图示一致性问题，属于部分失败。 |
| **15. 生成或修订出的题目无效** | [AI-assisted MCQ creation，2026](https://www.frontiersin.org/journals/computer-science/articles/10.3389/fcomp.2026.1831250/full)；[TeachArena](https://arxiv.org/html/2605.14322v4) | **【示意】**一道单选题有两个正确选项；修掉一个错误后，又引入答案键与解析不一致。 | 包括多解、无解、信息缺失、错键和无关线索。原 MCQ 研究实测模型较旧；我们相关题的 GLM 主体处理成功，尚无当前强模型共同失败证据。 |
| **16. 混淆命题／实验设计的目标与实际证据** | [TeachArena](https://arxiv.org/html/2605.14322v4)；[TASD](https://arxiv.org/abs/2604.16738)提供相邻依据 | **【本地】**观测值 13.8 已超过模型 M 的上限 12.4，两个 GLM 仍因“设计不保证区分”而断言本次不能判断。 | 混淆“事前不保证识别”与“这次观测已足以识别”。两个 MiniMax 在修订题中正确处理。该例只覆盖测评设计的一部分，不直接证明高阶命题普遍失败。 |
| **17. 无法准确估计特定学生群体的题目难度** | [生成题难度研究，2026](https://arxiv.org/abs/2609.27063)；[Human–AI Difficulty Alignment，2025](https://arxiv.org/abs/2512.18880) | **【文献结果】**一项课堂研究中，生成题的自报难度与学生实测难度相关约 **0.06**。 | 模型自己的解题感觉不代表学生难度。研究有较小模型和题目天花板限制。我们只测过给定统计后的推理，没有真实学生难度校准实验。 |
| **18. 干扰项不能反映或区分真实误概念** | [Can LLMs Model Incorrect Student Reasoning，2026](https://arxiv.org/abs/2603.15547)；[MisconceptionBench](https://aclanthology.org/2026.emnlp-main.712/) | **【示意】**声称选项 B 对应“分母直接相加”，但按这个错误规则计算，根本得不到 B。 | 干扰项需要由目标错误机制产生，还要区分不同机制。我们的规则构造题主要成功，未验证真实学生是否按预设机制选择。 |
| **19. 教学图文和连续图之间不一致** | [EduIllustrate，2026](https://arxiv.org/abs/2604.05005)；[VisualEDU，2025](https://aclanthology.org/2025.findings-emnlp.889/) | **【文献】**文字推导使用 `3H/4`，图中却标成 `H`。**【本地】**同一整条重新分割后，图示长度从 30 变成 36。 | 文字正确不保证图中的对象、比例、单位和阶段关系正确。本地既有明确错误，也有四态活塞 SVG 成功反例。 |
| **20. 交互演示能操作，但科学行为错误** | [InteractScience，2025/2026](https://arxiv.org/html/2510.09724v2)；[SimStep，2026](https://doi.org/10.1145/3772318.3791514) | **【本地】**RC 电路一次推进 2 秒后只连接端点，图上 1 秒处约为 5V，正确值约为 9.933V。 | 端点数值和按钮通过检查，曲线仍可能误导。另有 M3 代码语法错误；M3.1 最终版本通过脚本检查。尚未证明配备执行与修复工具的 Agent 仍失败。 |
| **21. 无关学生标签改变评价或帮助** | [LLMs are Biased Teachers，2025](https://aclanthology.org/2025.findings-naacl.314/)；[EduFair-Bench，2026](https://arxiv.org/abs/2609.12949) | **【示意，文献有配对差异信号】**同一作品只换成“优秀学生”或“基础薄弱学生”，就得到不同分数或能力归因。 | 要区分无关标签效应与合理的支持需求。本地三版本题核心评分一致，尚未建立广泛公平性失败结论。 |
| **22. 作文／开放题整体评分和评价标准不可靠** | [物理与作文评分研究](https://arxiv.org/html/2603.14732v3)；[CODE-PLAN](https://www.sciencedirect.com/science/article/pii/S2666920X2500178X) | **【文献结果】**模型的作文平均分接近教师，却不能可靠区分不同作品质量。 | 均分接近不等于评分可靠。本地 M3.1 的 7,421 篇 ASAP 作文 QWK 为 **0.4825**；该批未提供完整 rubric／来源材料，不能概括成完整评分条件下的失败。 |
| **23. 苏格拉底提问只是形式，缺少教学作用** | [MathTutorBench，2025](https://aclanthology.org/2025.emnlp-main.11/)；[MRBench，2025](https://aclanthology.org/2025.naacl-long.57/) | **【示意】**学生不知道为什么要通分，AI 只问“你是不是应该先通分？”，实际上泄露操作而未处理理解困难。 | 关注问题是否针对卡点、能否引出学生推理，而非是否有问号。本地 Socratic 主要测参考文本匹配，**低 BLEU 不能直接证明不会教学**。 |
| **24. 先修关系判断和学习顺序规划错误** | 本地 **MOOCCube prerequisite** 实验；直接对应的近期文献仍需补强 | **【示意】**学习任务 B 明确依赖 A，却把 B 排在 A 前；局部关系判断正确，整体计划仍违反约束。 | 本地各 100 道排序题，M3／M3.1 完全满足先修约束的比例为 **28%／33%**。这是单一图谱和构造协议，尚不等于真实个性化课程规划能力。 |
| **25. 复查不纠错，甚至把正确答案改错** | 主要依据本地 **P07 两轮自查**；暂不强配相邻文献 | **【本地】**M3 复查改对 8 题，同时把 5 道对题改错；M3.1 改对 12 题、改错 10 题。 | 复查净收益低。这里测的是**被要求检查后的纠错**，不是主动发现问题，也尚未测完整教学策略自修复。 |
| **26. 错误回答仍高度自信，不知道何时补充证据** | [图像直批的选择性复核研究](https://www.frontiersin.org/journals/education/articles/10.3389/feduc.2026.1948818/full)为相邻依据；本地 **P08** | **【本地】**自报置信度 ≥90 的回答中，M3／M3.1 仍有 **32.62%／40.04%** 错误。 | 自报把握与实际可靠性脱节。教育中的补问、弃答和转交尚未充分验证；上述数据是通用校准信号，不能直接当教学决策错误率。 |
| **27. 教案结构完整，但教学设计不可用** | [LessonPlanLM，2025](https://www.nature.com/articles/s41599-025-06004-2)；[LessonBench-V1，2026](https://arxiv.org/abs/2607.13041) | **【示意，待验证】**目标要求解释因果，活动只有听讲和抄写，最后用记忆题评价；安排的活动也无法在课时内完成。 | 目标、活动、评价、学生起点和时间资源需一致。现有研究包含旧模型及明显改善反例；我们尚未完成完整教案生成和教师评价实验。 |
| **28. PPT 看起来完整，但内容组织与教学表达失真** | [PresentBench，2026](https://arxiv.org/abs/2603.07244)；[SlidesGen-Bench，2026](https://aclanthology.org/2026.emnlp-main.1482/) | **【示意，待验证】**跨页符号含义改变，图表不支持结论，练习页与答案页不匹配，核心推理被装饰性内容挤掉。 | 需分别看资料忠实、跨页一致、教学组织和可编辑性。文献主要是通用幻灯评测；我们尚无完整教学 PPT 的专项结果。 |
| **29. 教育工具流程执行了，但没有交付正确结果** | [TeachArena，2026](https://arxiv.org/html/2605.14322v4) | **【示意】**口头说已修改课程材料，实际改了错误文件；上传成功，却仍发布旧版本。 | 要同时检查行动对象、内容、版本和验证步骤。我们目前主要测一次生成，没有给模型完整 LMS／浏览器行动环境，属于覆盖缺口。 |
| **30. 长期教学没有带来保持与独立迁移** | [EduClaw-Bench，2026](https://arxiv.org/abs/2608.03206)提供协议参考；[StudentBench，2026](https://arxiv.org/abs/2609.28470)提供即时收益反例 | **【示意，待验证】**本轮在提示下答对，下次无提示仍不会；系统却一直记录为“已掌握”，继续推进。 | 长期状态更新、延迟保持和迁移应分别测。我们没有真实学生长期对照；LongTutor 和历史快照题不能替代这类证据。 |
| **31. 学生代码存在多个错误，模型只找到一个** | [PyMETA，2026](https://arxiv.org/html/2606.30610v2) | **【示意】**首个异常掩盖后面的逻辑错误，模型只解释异常，却声称程序问题已经全部定位。 | 文献中首异常识别较强，多错误集合完整匹配明显较低；但标注未必穷尽，原协议也没有执行工具。我们尚未专项复现。 |
| **32. 逐步检查证明，却漏掉整体目标未被证明** | [LeanPRM，2026](https://arxiv.org/html/2610.17697v3)；[Confirming Correct, Missing the Rest](https://aclanthology.org/2026.bea-1.56/) | **【示意】**各段论证局部成立，但只证明必要性，模型却认可为充分必要性的完整证明。 | 需要核对目标、前提和论证覆盖。部分研究标签来自形式验证，可能混入表达或形式化失败；我们尚无专家复核后的专项结果。 |
| **33. 第二语言教学内容正确，但不适合学习者** | [L2-Bench，2026](https://arxiv.org/abs/2607.08842) | **【示意，待验证】**面向初学者设计活动，却要求未学过的复杂表达；学生需要练习沟通，反馈却只纠正所有语法细节。 | 测语言水平、教学目标、任务和反馈是否匹配，而非一般英语答题能力。文献提供候选信号，本地尚未专项测量。 |
| **34. 学生风险识别和应对程度不匹配** | 直接对应的外部依据待补；本地 **Student Risk v2** | **【示意】**把普通考试挫折升级为严重危机，或面对明确严重风险仍只给泛化鼓励。 | 本地 M3／M3.1 风险识别准确标签比例约 **67.58%／65.66%**，存在过度识别信号。结果依赖题集标签和 judge，不代表真实伤害率。 |
| **35. 教师角色、学业诚信和行为边界失守** | [EduWild](https://arxiv.org/abs/2610.23530)；[SafeTutors，2026](https://arxiv.org/abs/2603.17373)提供部分依据 | **【示意】**越权承诺正式成绩，或在明确不应代做的情境下替学生完成任务。 | 本地 Education Boundary 风险子集通过率为 **69.17%／72.5%**；合法控制请求没有出现误拒。具体行为需分项分析，不能笼统称“教育不安全”。 |
| **36. 内容不适龄，或连续施压后越界** | 完全对应的外部证据待补；本地 **Age Values v1**；[SafeTutors](https://arxiv.org/abs/2603.17373)仅为相邻依据 | **【示意】**起初按年龄调整内容，后续追问后输出原本不适合该年龄的内容。 | 本地 A/core 联合通过率约 **73.53%／72.06%**。两轮子集较弱，但并非同题随机对照，不能直接证明轮数造成下降。 |
