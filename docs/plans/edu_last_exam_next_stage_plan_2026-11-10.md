# Edu Last Exam：全方向实现与全量探索评测计划

日期：2026-11-10。状态：**37个方向的候选题包与受限环境已落实，作者离线验收通过；全量模型实验和独立复核尚未完成。** 本计划按用户确定的方向更新：将完整清单 01–37 全部纳入实现范围，完成一轮全方向探索后，再依据结果决定难题集与后续深测。取消只推进三个场景和最多六个案例的范围限制。

同日实施交付：[38个基础案例/82个投递版本](../../private/edu_last_exam_full_coverage_v1/README.md)、[题册](../../private/edu_last_exam_full_coverage_v1/questions.html)、[评分审阅册](../../private/edu_last_exam_full_coverage_v1/review.html)及[实际实现与未测子结论](../../reports/full_coverage_v1/implementation_status.html)。GLM-5.3-Flash获授权用于并发4的全量后台试跑；运行状态以独立输出目录的持久记录为准。

**文献与历史实验提供出题依据，本轮全量结果决定哪些场景对当前模型仍然困难。** 不要求某个方向先被今天两个 GLM 证明失败才允许出题，也不因它已出现成功例就停止覆盖。每个方向题量可以少，范围需要完整；原子能力只作可选解释。

本次依据[完整证据清单][inventory]、已有原回包与本地素材制定路线，未重新检索全部论文。逐项实施路线、素材入口和缺口见[37 项实施表](../../reports/research/edu-last-exam-full-coverage-implementation-2026-11-10.html)；[机器可读清单](../../data/edu_last_exam_full_coverage_v1/implementation_matrix.json)明确标为规划，不作为已完成题集。

## 1. 今天的实验改变了什么

原版与中性版都是 5 个任务包、12 个投递版本，主要采用一次 API 调用；历史记录和书面分支计划不等于已经执行多轮教学。

| 条件 | GLM-5.3 有效回答 | GLM-5.3 Flash 有效回答 | 当前状态 |
|---|---:|---:|---|
| 原版 scenario_v1 | 10/12 | 12/12 | 2 个 GLM 图片请求被接口拒绝；有作者内容审阅，独立语义评分待完成 |
| 中性版 scenario_neutral_v1，含补跑 | 10/12 | 12/12 | 3 个限流文本请求已恢复；仍有 2 个图片接口错误 |

依据：[原版 GLM summary][baseline-summary]、[原版 Flash summary][baseline-flash]、[补跑合并 summary][effective-summary]、[中性 Flash summary][neutral-flash]。共 **44 份有效回答、22 组原版—中性版配对**；不是 44 道独立题。补跑保留在独立目录，原运行记录不覆盖。[完整清单][inventory]第 2 节中性版的 7 回答／5 错误是补跑前快照。

此前对话中的 **13/22＝59.1%** 来自临时严格整份回答复核，不作为正式正确率继续使用。现行 [S03 rubric][history-reference] 的通过阈值为空，语义评分待审，并明确不跨场景汇总；Flash 电感题的局部问题也不应自动与明确错误反馈同级。需要重新形成可追溯的分项判定，而不是用临时总数决定题目难度。

已有证据为全量实现提供下列测量要求，不据此筛掉其他方向：

| 本轮观察 | 可定位例子 | 对下一步的影响 |
|---|---|---|
| 首错、错误参考核查和正确电路作品复核，核心判断大多成立 | S01 两包；S02-002 电路 | 现有题保留作有效性与回归控制；纳入本轮全量基线，不因已做对就从范围删除 |
| 分析保留未知条件，学生反馈却把它写成已知事实 | GLM 中性 S02-001b，前文要求查单位，反馈写“按原题电流单位（mA）”；A 分支还误写换算原因 | 测条件是否一直保持到扣分、反馈和交接，不笼统称为视觉失败 |
| 把学生自己算出的中间量记成题面给出的量 | Flash 中性 S03a 把 R07 的 6×4 当作题面直接提供，据此构造“首次只给因子”的诊断 | 增加信息来源对照；历史长度本身不是目标 |
| 将缺少独立证据升级为能力或干预效果定论 | GLM 中性补跑 S03b 写“不能自产”“模式已被证明无效” | 测诊断与行动是否受现有证据支持，而非是否使用固定谨慎话术 |

原始证据：[电感回答][inductor-response]第 41–63 行、[历史回答][history-response]第 24–54 行及 [R07 原记录][history-input]、[补跑回答][retry-history]第 13–16 行。原版 [S03b 回答][baseline-history]也把 R06 泛化成完整答案复述，虽然对学习效果保留了边界。因此目前只能提出提示敏感性假设，不能把所有中性版问题都归因于删提示。

## 2. 全量范围与题目来源

完整证据清单的 01–37 是覆盖目录，存在重叠，不要求一条对应一种新能力或固定一种题型。每条都需要可追踪的任务、来源、评分和完成状态；一份作品可支持不同任务，但各自测量边界必须单列，不能重复计为多个独立样本。

| 来源路线 | 实际工作 | 需要保留的依据 |
|---|---|---|
| 公开仓库已有题 | 导入完整题目、输入、必要上下文与评分；独立核验参考答案 | 仓库/版本/题号、许可状态、原始与本地 gold 的差异；不能把原标签匹配率直接当真实正确率 |
| 按原始文献机制实现 | 将文献描述的具体教育任务与失败条件做成可执行题，保留合理成功条件 | 原文位置、适用条件、改编部分、参考解及对照；标为机制改编，不冒充论文原例 |
| 本地已有实验错题 | 从原始回包定位实质错误，迁移完整任务并修复已发现的题面或 gold 问题 | 旧模型/日期/输入/错误输出、修订记录；改题后重新测，不能继承旧失败率 |

三条路线并列，按材料与场景的适配程度选用。成功例、正确作品、合法替代解也进入相应控制。不能只收集看起来容易让模型犯错的答案，随后用筛选后的比例代表整个教育领域。

**第一轮每个方向拟准备 1–3 个独立案例及必要控制。** 这是小样本全覆盖探索，不是逐个方向做大。37 个条目不机械等于 37–111 道互不重叠题；实际独立案例、子任务、对照版本和调用数以最终 manifest 分别统计。若某方向含多个不同子问题，明确本次覆盖了哪部分，缺哪部分。

## 3. 全部推进，按真实缺口安排实现

| 实现工作 | 纳入的方向与例子 | 完成的判据 |
|---|---|---|
| 文本任务与已有作品适配 | 首错、过程评价、锚定、命题、诊断、先修关系、开放证明、代码错误等 | 完整输入、正确参考、合理答案集合、关键错误和控制均可检查 |
| 多模态素材与评分 | 手写/图形、图像作业、音视频、适龄内容等 | 实际媒体送达；有独立读取或标注依据；识别、评价和接口问题分开 |
| 真正互动环境 | 申诉、流程恢复、帮助调整、连续提问、多轮施压等 | 模型行动产生后续观察；保存逐轮状态与分支；静态快照只能覆盖相应决策子视图 |
| 产物与工具环境 | 图示、科学演示、教案、PPT、LMS交付等 | 在允许的工具条件下，检查内容、结构、渲染与实际交付；代码生成和可调试Agent分别报告 |
| 真实数据支持的测量 | 学生难度预测、真实诊断效度、长期保持/迁移等 | 有目标群体及独立响应/学习证据。模拟状态测试可以同时实现，但不计作真实学习效果的直接测量 |

上述工作并行展开，不用于挑选只做哪几个方向。安全 34–36 全部纳入总实施与运行清单，结果保留独立分项。完整教案、PPT、语言和音视频等也进入实现，不再仅因本地尚未试跑而放在范围之外。

证据强度与实现进度是两列不同的状态：文献明确失败、本地实错、相邻研究或仅覆盖缺口分别记录；有研究依据不自动等于当前模型失败。依据不足的条目继续核查和构造明确标识的探索任务；不得将缺口本身当成已证实的短板。

## 4. 执行顺序

1. **完成 37 项逐条实施映射。** 每项落实三种来源中的路线、现有素材、任务形态、评分及缺口；不在此阶段按预期难度淘汰方向。本次已形成这份规划表，素材入口存在不等于题已实现。
2. **并行取题、改编和建设必要环境。** 现有 44 份回答的评分复核同步进行，为相关题提供协议修正；不阻挡其他方向的工作。新增题遵循 `cards → authored → export → validate → review`，被测面板模型不生成规范题。
3. **固定全量探索批次与评分。** 对每项明确实际覆盖的任务视图和子机制、参考/允许答案、关键错误、控制、模型输入与工具。先完成离线协议检查；未完成独立教师审核的候选可以有清楚标识的作者试跑，但不得称为已审定或冻结 benchmark。
4. **对整批可执行任务做全量运行。** 同一批任务使用预先确定的模型面板、条件和评分口径；实际API条件允许时保留既定的模型间串行、每模型并发4、后台运行及持久完成标记。图像/音视频和工具能力先做投递检查，不以接口不支持计能力零分。调用量按冻结的任务清单、对照和轮次具体化。
5. **全量结果出来后再分类与复测。** 分为已观察失败、当前成功、混合/不稳定、评分争议和输入/环境不可用；针对失败核查 gold、重跑及换模型家族验证。随后使用未参与改题的实例与模型确认，才讨论正式难题集。

第一轮主要获得广度与可定位的失败；重复实验和大样本分布估计安排在全量探索之后。GLM-5.3 与 Flash 可以沿用为前后对照，但属于同一家族；扩展模型面板需记录版本与供应商，不把两个 GLM 的结果外推为全部当前 LLM。

## 5. 怎样认定完成了全量

使用清单 37 项作为公开分母，分别统计：**有实施路线、已有题包、协议可执行、完成有效评测、完成独立复核**的方向数，同时列子机制覆盖。不能只跑就绪子集然后把其余方向悄悄去掉，称为 37 项全覆盖。

材料无法取得、媒体接口不支持、环境未完成、真实学生数据缺失，都保留为未完成项并注明具体原因。可以先执行已就绪任务以避免空等，但整个项目的全量完成条件不因此缩小；这些项也不能用弱代理悄悄补齐。

逐题状态与证据分开管理：`planned → cards → authored → exported → offline_validated → review / exploratory_run → freeze`。其中 trial 可早于独立 review，但 freeze 必须在 review、协议检查及多模型证据均完成之后。状态更新必须链接实际产物、回包和评分，不能把一行计划算作一道题。

## 6. 结果如何支持“哪个好、哪个不好”

按方向和任务视图报告正确/通过计数、关键错误、控制题表现、有效输入分母、重复稳定性和 judge 依赖；不能平均不同构念的原生指标得到一个总正确率。跨方向共用的案例和同题变体需标明依赖。

样例少时，只能说“本批任务中表现如何”；某方向暂时全对可以说明这批例子未暴露短板，还不足以说明该领域已解决。局部失误与错误反馈、误批、错误教学行动分别标注，避免任意加严评分来维持题目难度。

**最终产出是覆盖整个证据清单的实验图谱，然后从中筛选有可靠证据的难题。** 全量探索允许模型成功，成功结果本身也是需要保留的证据。本次已落实37项的候选任务、评分和受限环境；模型结果、独立复核及各方向未测子结论仍需继续完成。
