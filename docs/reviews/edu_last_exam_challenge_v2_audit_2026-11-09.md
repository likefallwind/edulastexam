# challenge_v2 逐题审查与第一版测试集决定

审查日期：2026-11-09  
范围：`private/edu_last_exam_pilot_v1/challenge_v2/` 的 21 个任务包，包含题面、刺激材料、参考解、离线检查和已有 GLM-5.3/GLM-5.3-Flash 探索性回包。

## 决定

第一版只冻结为**测试候选集**，不是已经验证困难或可发布的排行榜。选择 8 个任务包：

| 任务包 | 教育场景 | 状态 | 进入理由与修订 |

## 已确认的修订边界

### C2-01：不把合法的当前计算误判为概念错误

K3 中两组不合格品人数都是 1,200，因此 `(90% + 80%) / 2` 在这道题的实际数据上等于按人数加权的真阳性率。K3 可以批评为不可迁移的简写，但不能判为本题的首个实质错误；K4 才是首错，因为合格品人数 38,800 与 58,800 不相等。追问保留互换误报率的反事实，用来区分当前合法性和一般化能力。

### C2-09：让目标场景的分母可复核

原材料写“下一次一半强光、一半弱光地种 100 粒”，但 gold 使用了每个配方各 50 强光和 50 弱光的设定。现在题面已经明确写出 A、B 各 100 粒且各半强/弱光，避免模型或人工评分器猜测分配方式。

### C2-10：区分单次误差和差值误差

若两次读数各自误差界为 ±0.2g，前后差值的最坏误差界为 ±0.4g。只有真实变化大于 0.4g 时，才能仅凭误差界保证区分；具体一对读数是否已经区分，还要看读数本身和允许区间。不能把 ±0.2g 直接当成前后比较的误差。

### C2-12：引用真实记录而不是压缩成未经核对的计数

首版使用记录号作为证据：负号展开的早期无提示错误为 R03、R07、R11、R14，近期无提示成功为 R23、R24、R25、R26、R28、R32、R34、R38。固定费用遗漏的无提示记录为 R05、R10、R17、R27、R30、R35、R37、R40；R31 是提示后成功，R33/R39 是不支持“所有应用题都不会”的反证。这样不会把样本选择或任务类型差异伪装成学习增益。

### C2-13：不把一种教学话术当作唯一 gold

A 快照中，学生已经自己提出“乘 8”。可以先简短确认这个方法可行，再要求学生解释单位并完成图示；也可以不先确认，但必须保留学生的独立尝试。两者都不应代做关键推理。B 必须针对“每段含三个八分之一”的新困难提供实质支架；C 必须核验量的含义，不能因答案正确宣布掌握。

### C2-16：静态测评设计，不冒充真实多轮实验

当前 runner 只能一次性交付 prompt，因此 v1 将 C2-16 记为“测评设计/证据审查”任务。答案必须分别写出：点对在事前是否保证区分，以及给定实际读数后哪些模型相容。重复 `x=2` 的设计不能保证所有误差下区分，但实际读数 13.8 仍可能排除 M；异常 `(0.1, 7.9)` 则必须检查完整绝对读数，不能只看差值。

### C2-20：让交互产物的曲线错误可判

端点和状态接口通过不足以证明教学曲线正确。v1 的评分要求在 `advance(2)` 后检查中间时间点（例如 t=1，真实充电值约 9.9326V）和历史样本不可改写；浏览器/脚本验收与文本解释分开记录。

## 结果解释纪律

- v1 是小规模 test candidate，不能直接发布总通过率或声称“绝大多数 Agent 不通过”。
- C2-01、09、10、12、13、16 是核心文字/决策轨道；C2-03 是评分稳健性基准；C2-20 是独立 artifact 轨道。
- 同一任务包的多个 prompt/变体先按包报告，再报告变体；不把变体数量当成独立题数。
- 产物任务必须保存模型交付物、浏览器/脚本检查和人工审阅状态；未执行的 HTML/SVG 不能记作通过。
- 题目难度、跨模型失败和评分器一致性是三个独立结论，需分别测量。
